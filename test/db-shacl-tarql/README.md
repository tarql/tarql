\# db-shacl-tarql external tests



These test files were taken from the db-shacl-tarql project by Kurt Cagle:



https://github.com/kurtcagle/db-shacl-tarql



They are included here as external TARQL test cases for regression testing.



\## Structure



\- `tarql/` - TARQL/SPARQL transformation files from the original project

\- `csv/` - CSV input files from the original project's `test-data` directory

\- `ttl-expected/` - existing Turtle output files from the original project's `output` directory



The files are kept as close as possible to their original form so they can be used to verify TARQL behavior against real-world examples.
